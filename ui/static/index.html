Настройки SyncSave и Google Drive

Подключение Google Drive API Не авторизован
Как за 2 минуты получить бесплатные Client ID, Secret и Folder ID
  1. Откройте Google Cloud Console → создайте проект → включите Google Drive API.
  2. В разделе OAuth consent screen выберите External, добавьте свой Gmail и Gmail друзей в Test Users.
  3. В Credentials → Create Credentials → OAuth client ID выберите тип Desktop app — получите Client ID и Client Secret.
  4. На Google Диске создайте общую папку, дайте друзьям доступ «Редактор», скопируйте её ID из адресной строки после /folders/.
