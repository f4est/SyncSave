Google Drive API Не авторизован
Как за 2 минуты получить бесплатные Client ID, Secret и Folder ID
  1. В Google Cloud Console откройте APIs & Services → включите Google Drive API.
  2. Откройте Google Auth Platform → настройте экран (External) → добавьте свой Gmail и Gmail друзей в Audience → Test users.
  3. В Clients → Create Client выберите Desktop app → скопируйте Client ID и Client Secret.
  4. На Google Диске дайте друзьям доступ «Редактор» к общей папке и скопируйте её ID после /folders/.
