# SyncSave

Лёгкая программа для **кооперативной синхронизации сохранений игр** — бесплатный аналог SaveSync.  
Играйте в общий мир с друзьями без аренды сервера: один игрок загружает сохранение, остальные скачивают его позже, даже если первый ПК уже выключен.

---

## Скачать

Перейдите в раздел **[Releases](https://github.com/f4est/SyncSave/releases)** и скачайте **`SyncSave.exe`** (один файл ~8 МБ, установка не требуется).

## Основные возможности

- **7 способов синхронизации на выбор**:
  - **Google Drive** — общая папка на Google Диске.
  - **WebDAV** — Яндекс.Диск, Nextcloud, OwnCloud или домашний NAS.
  - **S3 / Cloudflare R2 / MinIO** — бесплатные 10 ГБ на R2 или любой S3-бакет.
  - **Git-репозиторий** — приватный репозиторий на GitHub / GitLab / Gitea.
  - **LAN / Radmin VPN / ZeroTier / Tailscale** — встроенный сервер раздачи напрямую между друзьями.
  - **Локальная / синхронизируемая папка** — Google Drive для ПК, OneDrive, флешка.
  - **Своя команда (CLI)** — подключение `rclone`, `rsync` или любого скрипта.
- **Приглашение друзей в 1 клик**: кнопка **«Поделиться»** создаёт код `SYNCSAVE://...` — друг нажимает **«Войти по коду»**, и мир подключается автоматически.
- **Защита прогресса**:
  - **История версий и откат** к любому сохранению в 1 клик.
  - **Авто-бэкап** перед каждой заменой локальных файлов.
  - **Защита от перезаписи** и кнопка **«Взять / Освободить хост»**.
- **24+ игр с автопоиском папок**: Valheim, Terraria, Palworld, Minecraft, Stardew Valley, Factorio, 7 Days to Die, Raft, Sons of the Forest, Project Zomboid, Enshrouded, Baldur's Gate 3 и др. + любые игры вручную.
- **Комфорт и минимальная нагрузка**:
  - Работа в системном трее, автозапуск с Windows, уведомления, режим экономии ОЗУ.
  - **5 тем оформления** и **3 языка** (Русский, English, Українська).

## Как начать играть с друзьями

1. Запустите `SyncSave.exe` и выберите удобный способ синхронизации в **Настройки → Облако**:
   - **Самый простой способ**: выберите *Локальная / Синхронизируемая папка* и укажите общую папку из установленного Google Drive для ПК / OneDrive.
   - **Без лишних программ (Google Drive API или WebDAV / Яндекс.Диск)**: введите данные подключения в Настройках и нажмите *Проверить*.
2. Нажмите **«+ Добавить»**, выберите игру (путь к сохранениям найдётся сам) и задайте одинаковое **Имя общего мира** у всех друзей.
3. Перед игрой нажмите **Скачать (Pull)**, после игры — **Загрузить (Push)** (или включите **Авто-синхронизацию**).
